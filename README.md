# 🚀 Developer Portfolio | Rihan Ali

A modern, responsive, and lightweight personal portfolio website built from scratch using pure **HTML5** and **CSS3**. Designed to showcase my projects, technical skills, and background as a Computer Science and Engineering undergraduate specializing in AI & ML.

## ✨ Features

* **Fully Responsive Design:** Optimized for seamless viewing across desktop, tablet, and mobile devices using modern CSS Flexbox and Grid layouts.
* **Pure CSS Styling:** Built without heavy component libraries or frameworks for lightning-fast load times and clean, maintainable code.
* **Interactive UI Elements:** Smooth scrolling, hover animations, and dynamic styling to enhance user experience.
* **Project Showcase:** Dedicated sections highlighting full-stack projects, microcontroller builds, and competitive programming progress.
* **Direct Contact & Social Links:** Quick-access links to GitHub, LinkedIn, and professional contact channels.

---

## 🛠️ Built With

* **Markup:** HTML5 (Semantic elements, accessibility best practices)
* **Styling:** CSS3 (Custom properties/variables, Flexbox, Grid, Media Queries)
* **Version Control:** Git & GitHub
* **Hosting & Deployment:** Vercel
